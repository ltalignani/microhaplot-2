## Question

Should this port include microhaplot2's external reference-panel merge
feature (upload a reference haplo_data CSV, validate locus overlap, merge
with the user's data, per-sub-tab "reference" badges), or stay scoped to
the 4 core sub-tabs on the user's own data?

## Answer

Excluded. It's a distinct, cross-cutting feature (touches all 4 sub-tabs
via badges and a dedicated sidebar section) that would roughly double the
complexity of this port. Deferred to a separate future effort. See the
map's "Out of scope".
